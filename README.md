# RizqVenturesOJT1
Rizq Connect – Mentor–Student Networking Platform
Rizq Connect is a community-oriented web platform that connects students, mentors, and partners. Inspired by professional networking sites, Rizq Connect focuses on mentorship, personalized learning, and real-world opportunities, helping users match by skills or interests and collaborate effectively.

🚀 Project Overview
Multi-role Platform: Cater to students, mentors, and partners
Skill-based Matching: Connect users by interests, expertise, and goals
Job & OJT Listings: Browse and apply for internships, jobs, and on-the-job training
Communication Tools: Real-time messaging, notifications, and community features
Dashboards: Track learning progress and access analytics (for admins)
Profile Management: Showcase experience, skills, and learning achievements

🛠️ Tech Stack
Frontend: React
Backend/Database/Auth: Supabase (PostgreSQL, Auth, Storage, Realtime)


🌟 Features
User Authentication and Registration
Role-based Dashboards (Student, Mentor, Partner)
Profile and Skill Management
Mentor–Student Matching System
Job & OJT Board
Admin Analytics Dashboard
Real-time Notifications & Chat
Progress Tracking

🚦 Getting Started
Clone this repo:
  git clone https://github.com/RizqVenturesHub/RizqVenturesOJT1.git
  cd rizq-connect

Install dependencies:
  npm install

Run the development server:
  npm start
